Voice widget demo

This page stands in for the client's website. The floating button in the corner is the widget. Click it, allow the microphone, and talk to the agent.

Add it to any website

Paste this one line before </body>:


  
Optional attributes: data-label (button text),
     data-color (brand colour), data-position="left".
     The site must be served over HTTPS; browsers only allow microphone access on secure pages
     (and on localhost).
